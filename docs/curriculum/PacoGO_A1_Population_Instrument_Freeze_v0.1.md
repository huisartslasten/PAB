# PacoGO A1 — Population + Instrument Freeze v0.1

## 1. Status

This document defines the freeze decision required before A1 power/precision planning and formal preregistration.

Scientific status: **freeze candidate; not empirical validation and not a preregistration**.

No parameter is frozen merely for convenience. Population, language, measures and administration must form one coherent measurement design.

## 2. Construct and study role

A1 — **Getallen representeren en verbinden** remains the reference/construction case.

Candidate developments:

- A1.D1 — Representational meaning
- A1.D2 — Mapping
- A1.D3 — Coordination

The D1 → D2 → D3 order remains a hypothesis to be tested, not an established developmental sequence.

## 3. Population decision

### 3.1 Current status

The repository does not yet contain a scientifically justified, externally verified target age/grade population for A1 validation.

Therefore **no exact age or grade range is frozen in v0.1**.

### 3.2 Required freeze fields

The formal freeze must specify:

- exact age range;
- grade/year range;
- expected mathematical curriculum exposure;
- administration language(s);
- school setting;
- inclusion criteria;
- exclusion criteria;
- recruitment source;
- expected attrition;
- accessibility/accommodation policy.

### 3.3 Language decision

PacoGO may support Dutch/Papiamento/other languages operationally, but the research administration language cannot be inferred from product capability.

The study language must be selected from the target population and the language validity of the selected external instruments.

A mixed-language study is permitted only if language is explicitly represented in the design and the measurement equivalence problem is addressed.

## 4. External instrument shortlist

### 4.1 Number-line estimation

**Status: RETAIN AS CANDIDATE.**

Role: convergent numerical-magnitude evidence and longitudinal indicator.

Freeze later:

- number range;
- task format;
- scoring model;
- administration mode;
- response-time use, if any;
- alternate forms for repeated waves.

Reason for not freezing yet: these choices depend materially on the final population and construct interpretation.

### 4.2 Independent magnitude comparison

**Status: RETAIN AS CANDIDATE.**

Role: convergent numerical-magnitude evidence using a response format distinct from PacoGO.

Freeze later:

- symbolic/non-symbolic format;
- item range;
- response mode;
- response-time use, if any;
- alternate forms.

### 4.3 Broad mathematics criterion

**Status: CANDIDATE — TEMA-3 ONLY IF POPULATION AND LANGUAGE FIT.**

TEMA-3 cannot be frozen until its age range, language/administration suitability, licensing and practical feasibility are confirmed for the final study population.

If it is not suitable, another independently administered broad mathematics criterion must be selected before preregistration.

### 4.4 Non-symbolic quantity measure

**Status: OPTIONAL.**

Include only if the final construct model requires discrimination between numerical-symbolic representation and more general quantity processing.

## 5. Selection rules

The final external-measure set must satisfy all of the following:

1. Construct relevance is explicit.
2. The measure is independent of PacoGO scoring.
3. The response format does not simply reproduce the PacoGO task.
4. Reliability evidence is available or can be established in the target study.
5. Administration is feasible for the target population.
6. Language validity is defensible.
7. Licensing/permission is resolved before data collection.
8. Repeated administration does not create unacceptable retest contamination.
9. The measure contributes to a pre-specified estimand.
10. Its interpretation does not exceed what the measure can validly support.

## 6. Provisional instrument bundle

Until the population is frozen, the study carries the following **candidate bundle**:

- PacoGO A1 task/evidence battery;
- independent number-line estimation;
- independent magnitude comparison;
- independent broad mathematics criterion;
- optional non-symbolic quantity measure.

This is a design bundle, not a final administered battery.

## 7. What is deliberately not frozen

The following remain open because freezing them now would create unsupported assumptions:

- exact age/grade;
- exact administration language;
- exact commercial instrument;
- exact number-line task;
- exact magnitude-comparison task;
- exact broad mathematics criterion;
- exact wave spacing;
- exact power assumptions;
- final primary statistical model.

## 8. Power-analysis consequence

No numeric sample size is frozen by this document.

Power/precision planning must follow population and instrument selection because those choices determine plausible variance, effect-size assumptions, repeated-measure structure, attrition and model complexity.

The next quantitative step must therefore use explicit sensitivity analysis rather than a generic sample-size rule.

## 9. Preregistration gate

A1 reaches **instrument/population freeze complete** only when:

- target population is explicitly justified;
- administration language is fixed;
- every primary external measure is named;
- licensing/permission is resolved;
- exact task forms and scoring are fixed;
- measurement occasions are fixed;
- primary estimands are fixed;
- power/precision assumptions are documented.

Until then, the study remains in design-freeze preparation.

## 10. Decision

**Decision: DO NOT freeze an exact population or final instrument set yet.**

The scientifically correct next step is to obtain the missing population and feasibility evidence, then perform the quantitative power/precision analysis from the resulting design.
