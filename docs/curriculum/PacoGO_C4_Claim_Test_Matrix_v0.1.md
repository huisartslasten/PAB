# PacoGO C4 Claim Test Matrix v0.1

**Status:** candidate working specification  
**Epistemic status:** `[S]/[O]`  
**Purpose:** operationalize C4 for the current A1/B1/FR2 vertical prototypes without treating the candidate developmental ordering as established fact.

---

## 1. Purpose and boundary

C4 asks whether a proposed developmental interpretation explains observed evidence better than plausible simpler or competing explanations.

This matrix does **not** establish that the developments are real or ordered. `candidate_order` is treated only as a hypothesis label. A C4 result can support, weaken, narrow, contradict, or leave a developmental claim indeterminate.

The current registry remains `candidate`. The matrix therefore defines what would count as evidence **for and against** the claims before learner data are interpreted.

### Core test

For each development:

```text
candidate development
        ↓
expected evidence pattern
        ↓
observations across task variation
        ↓
alternative explanations tested
        ↓
C4 comparison
        ↓
interpretation within scope
```

A correct answer by itself is insufficient. Evidence should include response process where the claim requires it, independence, variation, and contradiction handling.

---

## 2. Cross-skill C4 requirements

Every development test should specify:

1. **Positive pattern** — what observations would support the candidate interpretation.
2. **Counterevidence** — what observations would weaken or contradict it.
3. **Discriminating variation** — which task changes are necessary to distinguish the claim from a simpler explanation.
4. **Response-process evidence** — what the learner's strategy, explanation, representation, or action must show.
5. **Alternative explanations** — plausible non-developmental explanations that must be examined.
6. **Scope** — the contexts in which the conclusion is allowed to apply.
7. **Revision consequence** — what happens if the predicted pattern is not observed.

Repeated observations are not automatically independent evidence. Repeated exposure to the same task surface must not be counted as developmental replication.

# 3. A1 — Getallen representeren en verbinden

## A1.D1 — Representational meaning

**Candidate definition:** een getal/hoeveelheid als betekenisvolle representatie herkennen.

**Associated claim:** A1.C1 — de leerling kan een numerieke representatie betekenisvol identificeren.

### Positive evidence pattern

Evidence supports D1 when the learner can identify the numerical value/quantity and explain or demonstrate the correspondence across more than one representation or task surface, without requiring a familiar item layout.

Useful evidence includes:

- number-to-quantity correspondence;
- quantity-to-symbol correspondence;
- placement or interpretation on a number line;
- explanation that remains consistent when surface layout changes;
- response-process evidence showing attention to quantity/value rather than a memorized visual cue.

### Counterevidence

D1 should be weakened when:

- correct answers disappear after superficial layout changes;
- the learner consistently relies on a cue unrelated to numerical value;
- explanations do not correspond to the selected value/quantity;
- performance is correct only for practiced items and not for matched novel items;
- the apparent success is fully explained by task familiarity or prompting.

### Discriminating variation

Minimum useful contrasts:

- familiar vs altered representation layout;
- numeral vs quantity representation;
- number line vs non-number-line representation;
- independent vs minimally prompted response.

### Alternatives to examine

- item familiarity;
- visual cueing;
- language comprehension;
- representation-specific familiarity;
- task difficulty.

### C4 interpretation rule

A1.D1 is not supported merely because correctness is high. Support requires a coherent evidence pattern that survives at least one meaningful surface/representation change and cannot be adequately explained by the simpler alternatives within the tested scope.

---

## A1.D2 — Mapping

**Candidate definition:** dezelfde numerieke waarde tussen representaties kunnen koppelen.

**Associated claim:** A1.C2.

### Positive evidence pattern

The learner maps the same value across representations and preserves the invariant numerical quantity when representation, format, or surface changes.

Examples of informative evidence:

- numeral ↔ quantity;
- numeral ↔ number-line position;
- quantity ↔ number-line position;
- two representations created by the learner for the same value;
- explanation of what remains invariant.

### Counterevidence

D2 should be weakened when mapping fails systematically under a representation change while the original familiar mapping remains intact, or when correct mappings can be explained by memorized pairs rather than value correspondence.

### Discriminating variation

- representation pair changes;
- order of presentation changes;
- number magnitude changes;
- surface form changes;
- low-language transfer condition.

### Alternatives to examine

- memorized pairings;
- representation-specific strategy;
- task familiarity;
- language comprehension;
- general task difficulty.

### C4 interpretation rule

Support requires stable mapping across varied representations with response evidence consistent with invariant numerical value. Failure on a novel representation is counterevidence only when the task is otherwise interpretable and the alternative explanations have been considered.

---

## A1.D3 — Coordination

**Candidate definition:** meerdere representaties doelgericht en flexibel kunnen coördineren.

**Associated claim:** A1.C3.

### Positive evidence pattern

The learner independently selects, combines, or switches between multiple representations for a numerical purpose and maintains the same underlying value.

Informative evidence includes:

- choosing a useful representation without being told which one to use;
- translating between more than two representations;
- using one representation to verify or explain another;
- changing representation when the task demands it;
- maintaining the numerical invariant across the coordination.

### Counterevidence

- coordination occurs only after explicit prompting;
- representations are selected but not meaningfully connected;
- switching representation causes loss of value correspondence;
- performance depends on one fixed representation;
- apparent coordination is fully explained by practiced task sequencing.

### Discriminating variation

- choice vs prescribed representation;
- two vs three representations;
- verification requirement;
- changed task surface;
- independent vs prompted condition.

### Alternatives to examine

- procedural familiarity;
- cueing;
- task difficulty;
- representation-specific skill;
- language/context effects.

### C4 interpretation rule

D3 requires evidence of **functional coordination**, not merely successful completion of a multi-step task. The learner's actions must show that representations are being used as connected representations of the same quantity.

# 4. B1 — Optellen

## B1.D1 — Samenvoegen begrijpen

**Candidate definition:** begrijpen dat hoeveelheden kunnen worden samengevoegd en dat de totale hoeveelheid de som representeert.

**Associated claim:** B1.C1.

### Positive evidence pattern

The learner identifies an addition relation between parts and whole and can represent or explain why the total corresponds to combining the quantities.

Useful contrasts:

- concrete/quantity representation vs symbolic notation;
- changed context with the same underlying addition relation;
- explanation vs answer-only response.

### Counterevidence

- operation selection changes when context changes despite preserved part-whole relation;
- explanation indicates a different operation;
- correct answer is present but response process shows item recall rather than combining;
- performance is dependent on a familiar surface or cue.

### Alternatives to examine

- memorization;
- item familiarity;
- language comprehension;
- task difficulty;
- cueing.

### C4 interpretation rule

A correct sum is insufficient. Support requires evidence that the learner represents the relation between parts and whole, preferably across at least two task surfaces.

---

## B1.D2 — Optelling als getalrelatie uitvoeren

**Candidate definition:** optellingen representeren en uitvoeren met verschillende getalgroottes en representaties.

**Associated claim:** B1.C2.

### Positive evidence pattern

The learner performs addition correctly while preserving the relation between addends and sum across changes in magnitude and representation, with a coherent strategy.

### Counterevidence

- performance collapses when magnitude changes while surface remains familiar;
- symbolic correctness is high but representation of the relation is inconsistent;
- prompted success does not transfer to a matched independent item;
- strategy is inconsistent with the claimed operation.

### Discriminating variation

- small vs larger magnitudes;
- symbolic vs quantity/visual representation;
- different response formats;
- prompted-to-independent matched items;
- novel but structurally equivalent problems.

### Alternatives to examine

- calculation fluency only;
- memorization;
- prompt dependence;
- cueing;
- task familiarity.

### C4 interpretation rule

D2 is supported only when execution remains conceptually coherent under relevant variation. Fast or correct calculation alone is not evidence of the developmental interpretation.

---

## B1.D3 — Strategisch en flexibel optellen

**Candidate definition:** een passende aanpak kiezen, uitvoeren en controleren wanneer meerdere oplossingsroutes mogelijk zijn.

**Associated claim:** B1.C3.

### Positive evidence pattern

The learner independently chooses a reasonable strategy, adapts it to the task, and checks whether the result is plausible or consistent.

Evidence should distinguish:

- strategy selection;
- execution;
- monitoring/checking;
- independence.

### Counterevidence

- the learner follows a single taught procedure regardless of task structure;
- strategy choice is prompt-dependent;
- checking is verbalized but not functionally connected to the result;
- a correct answer occurs without evidence of strategy selection or control.

### Discriminating variation

- tasks with multiple viable strategies;
- changed magnitude;
- changed representation;
- explicit vs absent strategy cue;
- requirement to verify.

### Alternatives to examine

- procedural training;
- cueing;
- task familiarity;
- general executive demand;
- language demand.

### C4 interpretation rule

D3 requires evidence of adaptive strategy selection and monitoring, not simply multiple correct solutions.

---

## B1.D4 — Geïntegreerd optellen

**Candidate definition:** optellen betrouwbaar en flexibel toepassen onder variërende representaties, getalgroottes en contexten.

**Associated claim:** B1.C4.

### Positive evidence pattern

The learner preserves the addition relation across meaningful variation and transfers it to a new representation/context without explicit indication of the intended strategy.

### Counterevidence

- performance depends strongly on one representation;
- transfer fails while practiced items succeed;
- independence disappears under novel context;
- apparent robustness is attributable to repeated practice with the same task family.

### Discriminating variation

At minimum, combine variation in:

- magnitude;
- representation;
- context/surface;
- response format;
- prompting.

### Alternatives to examine

- task familiarity;
- procedural fluency;
- context-specific learning;
- language comprehension;
- representation-specific skill.

### C4 interpretation rule

D4 should be interpreted as a broad integration hypothesis only within the tested variation scope. A failure in one untested domain must not be generalized into global non-mastery.

# 5. FR2 — Breukequivalentie herkennen en gebruiken

## FR2.D1 — Equivalentie herkennen

**Candidate definition:** herkennen dat verschillende breuken dezelfde hoeveelheid/waarde kunnen representeren.

**Associated claim:** FR2.C1.

### Positive evidence pattern

The learner correctly distinguishes equivalent from non-equivalent fractions and can justify the relationship through value rather than superficial visual/symbolic similarity.

Useful contrasts:

- area model vs symbolic notation;
- visually familiar vs unfamiliar representations;
- equivalent pairs with different numerators/denominators;
- non-equivalent pairs with superficially similar numbers.

### Counterevidence

- choices change when visual surface changes while mathematical relation remains constant;
- learner relies on numerator/denominator similarity without considering value;
- correct classification occurs but explanation contradicts equivalence;
- performance is limited to familiar fraction forms.

### Alternatives to examine

- surface familiarity;
- cueing;
- representation-specific familiarity;
- language comprehension;
- task difficulty.

### C4 interpretation rule

Correct classification plus an incorrect rationale is not clean positive evidence. It should be coded according to the evidence targets and may count as contradiction for the relevant interpretation.

---

## FR2.D2 — Equivalentie verklaren

**Candidate definition:** equivalentie onderbouwen via representatie, verhouding of andere betekenisvolle redenering.

**Associated claim:** FR2.C2.

### Positive evidence pattern

The learner explains why two fractions represent the same value and maintains the explanation when the representation changes.

Possible evidence:

- equal area/length interpretation;
- partitioning relationship;
- multiplication/division relationship between numerator and denominator;
- number-line position;
- another internally coherent value-based explanation.

### Counterevidence

- explanation is only a memorized verbal rule;
- explanation does not match the represented values;
- equivalent pairs are recognized but changed representations break the explanation;
- correct output is paired with reasoning that would also predict incorrect equivalences.

### Discriminating variation

- area model → number line;
- visual → symbolic;
- familiar → unfamiliar partitioning;
- explanation format changes;
- low-language visual condition followed by explanation.

### Alternatives to examine

- memorized rule;
- representation-specific familiarity;
- language comprehension;
- cueing;
- task familiarity.

### C4 interpretation rule

D2 requires evidence of a value-preserving explanation. A rule stated correctly is not enough if the response process does not demonstrate that the rule is connected to the equivalence relation.

---

## FR2.D3 — Equivalentie functioneel gebruiken

**Candidate definition:** equivalentie doelgericht gebruiken om te vergelijken, representeren, rekenen of een probleem eenvoudiger te maken.

**Associated claim:** FR2.C3.

### Positive evidence pattern

The learner independently invokes equivalence because it helps accomplish another mathematical goal.

Examples:

- rewriting a fraction to compare it;
- choosing an equivalent representation that simplifies a calculation;
- using equivalent fractions to connect a visual and symbolic solution;
- explaining why an equivalent form is strategically useful.

### Counterevidence

- equivalence is used only after explicit instruction;
- learner can generate equivalents but does not use them functionally;
- strategy choice is tied to a practiced template;
- equivalence transformation produces a formally correct but mathematically unhelpful result.

### Discriminating variation

- task where equivalence is useful but not explicitly named;
- multiple possible strategies;
- changed representation;
- transfer to a new mathematical purpose.

### Alternatives to examine

- procedural training;
- cueing;
- template familiarity;
- calculation skill;
- language/context effects.

### C4 interpretation rule

D3 is a functional-use hypothesis. The key evidence is spontaneous or independently selected use of equivalence for a second purpose, not the ability to produce an equivalent fraction on demand.

# 6. Cross-skill decision table

| C4 outcome | Meaning | Curriculum consequence |
|---|---|---|
| `NOT TESTABLE YET` | Required evidence/variation is not available | Do not interpret development |
| `INDETERMINATE` | Evidence is insufficient or alternatives remain unresolved | Keep Candidate; collect targeted evidence |
| `SUPPORTED WITHIN SCOPE` | Candidate explanation fits evidence better than tested alternatives within scope | May inform further validation; does not establish ordering |
| `CONTRADICTED WITHIN SCOPE` | Observed pattern conflicts materially with candidate explanation | Narrow/revise/reject candidate interpretation |
| `REVISE CANDIDATE` | Data suggest the construct is useful but the formulation is inadequate | Create versioned candidate revision; do not silently alter registry |

No C4 outcome automatically changes the runtime registry.

---

# 7. What this means for the existing pilot task set

The existing A1/B1/FR2 pilot tasks already contain useful variation and countertasks. They should now be treated as **C1-C3 measurement-development fixtures plus preliminary C4 discriminators**, not as a complete C4 validation design.

Before empirical C4 analysis, the task set should be expanded where a development cannot be distinguished from its alternatives with the existing tasks.

In particular:

- A1 needs stronger multi-representation coordination tasks for D3.
- B1 needs stronger strategy-selection and checking tasks for D3 and integrated transfer for D4.
- FR2 needs stronger functional-use tasks for D3 and explanation tasks that distinguish value reasoning from memorized rules.

The next task-design artifact should therefore be a **C4 Discriminating Task Set**, linked to this matrix but versioned separately from the core curriculum registry.

---

# 8. Boundary with C5

This matrix deliberately does not test whether:

`D1 < D2 < D3 < D4`

is empirically true.

C4 asks whether the proposed developments describe distinguishable patterns that outperform plausible alternatives.

C5 asks whether the developments have a defensible developmental ordering.

Therefore a development can receive `SUPPORTED WITHIN SCOPE` in C4 while its `candidate_order` remains completely unvalidated.

---

# 9. Boundary with infrastructure

A C4 claim cannot be tested if PacoGO cannot generate the required observation.

Therefore each C4 test must eventually resolve to a concrete task instance and interaction capability:

```text
claim
  ↓
evidence target
  ↓
task model
  ↓
task instance
  ↓
interaction
  ↓
observable response process
  ↓
evidence coding
```

This is why the empirical curriculum work and the PacoGO interaction infrastructure must now converge in a **vertical prototype**, rather than being developed as two isolated projects.
