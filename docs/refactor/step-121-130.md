## Important finding
V4.78 uses **different visibility rules in different contexts**. There is no safe universal `visibleLessons` predicate to apply everywhere.

| Context | Verified V4.78 rule |
|---|---|
| Student dashboard | current student + `!archived` + `!deleted` |
| Subject page | matching subject + current student + `!archived` + `!deleted` |
| Preparation stats | current student + `!archived` |
| Student sidebar | current student + `!archived` + `!deleted` |
| Agenda → lesson matching | current student + `!archived` + lesson items |
| Parent active lessons | student + `!archived` + `!deleted` |
| Parent archived lessons | student + `archived` + `!deleted` |
| Archive recovery | `archived && !deleted` |
| Trash recovery | `deleted` |

This matrix is intentionally explicit. We must not “clean up” these differences into one generic filter because doing so could change existing V4.78 behavior.
