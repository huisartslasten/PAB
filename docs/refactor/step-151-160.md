## Verified V4.78 editor field matrix

The V4.78 editor persists more than the four basic lesson fields. The verified editor payload includes:

- `student`
- `subject`
- `subvak`
- `title`
- `type`
- `explanation`
- `ai_check_answers`
- `ai_instruction`
- `editor_labels` for spelling labels

The test-date value is deliberately kept outside the lesson payload because V4.78 stores it through the separate test-calendar mechanism.

## Verified lesson types

V4.78 exposes six editor types:

- `words`
- `questions`
- `dictation`
- `math`
- `spelling`
- `custom`

The refactor now represents all six instead of silently treating the latter types as ordinary word lessons.

## Verified item shapes

### words / custom

Each meaningful row can contain:

- `question_parts`
- `answer_parts`, with `role` equal to `answer` or `extra`
- `question`
- `answer` containing only required answer parts
- `hint`
- `min_words`
- `required_terms`
- deterministic `sort_order`

### questions / dictation

The row contains question and answer parts. Required answer parts form the persisted `answer`; extra parts remain represented in `answer_parts` but are not included in the evaluated answer string.

### math

The same part structure is used, but V4.78 requires every required answer part to be numeric before the item is accepted.

### spelling

Required answer forms are joined with the verified V4.78 separator ` || `. Extra answer forms remain in `answer_parts` but are excluded from the evaluated answer string.

## Important correction

The previous refactor boundary supported only three lesson types and reduced word/question items to a simple question/answer pair. That was too lossy for parity. The boundary has now been expanded to preserve the verified V4.78 field and item structure.

This is still a deterministic data-model extraction. No AI behavior has been introduced into the lesson editor by this change.
