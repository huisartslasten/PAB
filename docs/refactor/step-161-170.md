## Verified V4.78 round-trip contract
Existing lesson editing reconstructs editor rows from `lesson_items`.

### Question parts
- Prefer persisted `question_parts` when present.
- Otherwise fall back to the persisted `question` value as one question part.

### Answer parts
- Prefer persisted `answer_parts` when present.
- For non-spelling types, a fallback `answer` string is split on newline.
- For spelling, a fallback `answer` string is split on ` || `.
- Answer-part roles are `answer` or `extra`.

### Item metadata
- `hint`, `min_words`, and `required_terms` are preserved for word/custom items.
- `sort_order` remains the ordering field.
- Math keeps the persisted numeric answer shape; numeric validation remains part of deterministic item building, not hydration.

### Lesson-level fields
The editor round-trip boundary preserves:
- `student`
- `subject`
- `subvak`
- `title`
- `type`
- `explanation`
- `ai_check_answers`
- `ai_instruction`
- `editor_labels`

Test date remains outside the lesson payload, matching the existing V4.78 test-calendar boundary.
