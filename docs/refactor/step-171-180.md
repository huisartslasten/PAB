## Persistence test correction
The editor-service test previously asserted an incomplete persistence sequence. The actual lesson service performs:
- new lesson: insert lesson → delete existing lesson items → insert lesson items
- existing lesson: update lesson → delete existing lesson items → insert lesson items

The test now asserts the table-aware sequence rather than accidentally treating the lesson insert and item insert as one operation. This matches the extracted lesson service.
