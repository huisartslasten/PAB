## Lesson player parity boundary
The TEST V4.78 reference was inspected directly before extracting the player boundary.

Verified V4.78 practice behavior:
- `startPractice(type)` shuffles the lesson items.
- Practice keeps a `remaining` set containing all lesson-item ids.
- The next practice item is chosen from the remaining items.
- A correct answer removes the current item from `remaining`.
- A wrong answer leaves the item in `remaining`, so it can return later.
- Practice tracks attempts.
- The activity finishes when no remaining items are left.
- Words/custom use answer grading; custom lessons can use fixed comparison when `ai_check_answers` is disabled.
- Dictation accepts only persisted answer-role forms and uses AI speech for playback.
- Math uses numeric comparison.
- Spelling compares both forms separated by ` || `.
- Fixed word rules (`min_words` and `required_terms`) are checked before semantic AI grading.
- The learner's entered answer is shown again in the practice feedback.
- Hints and extra answer information remain part of the player data contract.

Verified V4.78 test behavior:
- `startTest(type)` shuffles the lesson items once.
- Test uses an index and records answers in order.
- Test stores `startedAt`.
- Feedback is deferred until the end for the test flow.
- Dictation uses AI speech playback.
- Spelling compares both forms.
- Math uses numeric comparison.
- Words/custom use semantic grading, with custom lessons able to disable AI grading.
- On completion V4.78 calculates the score, saves `test_attempts` and `test_attempt_answers`, then opens the result page.

Verified V4.78 question flow:
- Question lessons use a separate practice-style activity.
- Questions are shuffled.
- The learner enters an answer, chooses `Antwoord bekijken`, sees both the entered answer and example answer, then self-marks `Goed` or `Nog niet`.
- The flow advances until all questions have been viewed, then offers navigation back to the lesson.
