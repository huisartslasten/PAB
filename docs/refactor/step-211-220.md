## Player persistence boundary
A dedicated persistence boundary has been added at:
- `src/features/lessons/player-persistence.js`

The boundary performs the intended persistence sequence:
1. insert the test attempt;
2. obtain the generated attempt id;
3. attach that id to answer rows;
4. insert test-answer rows;
5. return the saved attempt and saved answers.

The module is additive and unmounted.

## Result boundary
A pure result-model boundary has also been added at:
- `src/features/lessons/player-result.js`

This currently provides a small deterministic result representation from completed answer records. It has no UI, persistence, or navigation responsibilities.
