## Important unresolved boundary
`src/features/lessons/activity-factory.js` still points to the older:
- `practice-engine.js`
- `test-engine.js`
- `question-engine.js`

The newer `player-session.js` exists, but its session API differs from the older engine contracts. Replacing the factory now would therefore be unsafe.

Consequently:
- no activity-factory rewrite was made;
- no runtime wiring was made;
- no legacy engine was deleted;
- no DOM behavior was changed.

There is also a competing older `src/features/lessons/choice.js` contract. It was deliberately left untouched until actual runtime usage is proven. The active new choice boundary is `lesson-choice.js`, consumed by `choice-flow.js`.
