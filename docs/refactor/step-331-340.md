## Extracted contract
`collectItems()` reads the current lesson type and editor rows.

- `words` / `custom`:
  - question parts are trimmed and empty parts removed
  - answer parts retain `{ text, role }`
  - only `role === 'answer'` values form `answer`
  - word rules add `hint`, `min_words`, and `required_terms`
- `questions`:
  - question parts and answer parts are collected the same way
- `dictation`:
  - same deterministic question/answer shaping
- `math`:
  - same shaping, but the required answer values must all satisfy `Number.isFinite(Number(value))`
- `spelling`:
  - required answers are joined with the exact separator ` || `
- every accepted row receives its zero-based `sort_order`
- rows without question parts or required answer parts are omitted
