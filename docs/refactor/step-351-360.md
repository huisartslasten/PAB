## Parity correction found
`editor-items.js` was carrying `hint`, `min_words`, and `required_terms` into every editor type when those fields happened to exist on a row. V4.78 only collects these fixed-answer rules in the `words` / `custom` path.

Correction:
- Word rules are now emitted only for `words` and `custom`.
- Unknown editor types no longer silently fall back to `words`; they return no items, matching the explicit V4.78 type branches.
