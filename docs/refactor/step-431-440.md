## Source-proven V4.78 authentication
The authoritative V4.78 runtime defines:

- `currentSession` as the active Supabase session state;
- `PARENT_IDS` as the allow-list of parent user ids;
- `isParentLoggedIn()` as `!!currentSession && PARENT_IDS.has(currentSession.user.id)`;
- `requireParent()` as the save-entry guard;
- denied save access shows the exact message `Alleen ouders kunnen lessen wijzigen. Log eerst in.` and returns `false` after `showHome()`;
- successful access returns `true`.

The new adapter keeps the authorization decision separate from UI by injecting `onDenied` rather than calling `showMessage()` or navigation itself.

## Source-proven V4.78 DOM/editor extraction
The authoritative `saveLesson()` reads these editor values before `collectItems()`:

- `#lessonSubject` → trimmed subject;
- checked `input[name=lessonStudent]`, falling back to `currentStudent`;
- `#lessonName` → trimmed title;
- `#lessonExplanation` → trimmed explanation;
- `#lessonType` → type;
- `#lessonSubvak` → trimmed entered subvak;
- matching existing lesson for the same student/subject and normalized subvak key → preserve canonical existing subvak spelling;
- `#lessonAiCheckAnswers` → boolean checked state;
- `#lessonAiInstruction` → trimmed instruction;
- spelling-only editor labels through `getSpellingLabels()`;
- `#lessonTestDate` → test date;
- `currentLesson?.id` → update id when editing.

The adapter does not call `collectItems()`. Item collection remains the already-proven independent boundary.

## New runtime boundary
Added:

- `src/features/lessons/lesson-save-runtime-adapter.js`

Exports:

- `isAuthorizedParent(session, parentIds)` — pure authorization predicate;
- `requireParentAccess({session, parentIds, onDenied})` — authorization gate with injected denial handling;
- `readLessonEditorDraft({...})` — DOM/editor-state extraction with injected document, lesson list, current student/lesson, and subvak normalization.

The adapter contains no Supabase calls, localStorage, rendering, navigation, `showMessage`, application-state mutation, or lesson-item collection. It returns a frozen draft object suitable for the next orchestration boundary.
