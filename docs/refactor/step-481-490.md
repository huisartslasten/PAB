## Source-mapped remaining runtime responsibilities
The authoritative V4.78 `saveLesson()` call site was checked after the coordinator boundary. The remaining application responsibilities are:

1. on validation failure, write the exact validation message to `#editorError` and reveal it;
2. on persistence failure, write `Opslaan mislukt: <error.message>` to `#editorError` and reveal it;
3. after successful coordinator completion, set `currentSubject` and clear `currentLesson`;
4. refresh the rendered test calendar;
5. refresh page sidebars;
6. show the exact success message as a success notification.

The coordinator already owns lesson persistence, reload, post-persistence saved-lesson resolution, and local test-calendar synchronization. The new runtime-effects boundary therefore does **not** repeat those responsibilities.
