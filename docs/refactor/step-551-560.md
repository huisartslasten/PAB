## Implementation
A source-contract assertion was added to `test/lesson-save-runtime-source-contract.test.js` requiring that `index.html` contain neither:
- `async function saveLesson()`
- `function saveLesson()`

The legacy function was then removed from `index.html` as one deliberate integration step. The removal was executed against the exact V4.78 function boundary and verified by a dedicated one-time GitHub Actions migration gate. That migration workflow succeeded and was immediately removed so no migration mechanism remains in the product repository.

No fallback, duplicate implementation, timeout, compatibility shim, or behavioral patch was added.
