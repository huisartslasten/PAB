## Boundary
The remaining V4.78 lesson-loading runtime path was audited against the authoritative TEST V4.78 source and extracted from the `index.html` monolith.

## V4.78 contract preserved
The legacy `loadLessons()` path:
- queries `lessons` with `*, lesson_items(*)`;
- orders lessons by ascending `id`;
- sorts each lesson's `lesson_items` by ascending `sort_order`;
- stores the loaded lesson collection in application state;
- calls `showHome()` after a successful load;
- shows the exact V4.78 error message `Lessen laden mislukt: <message>` with `error` type and does not navigate after a failed load.
