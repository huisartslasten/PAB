# PacoGO refactor — steps 61–70

Baseline: TEST V4.78
Branch: `refactor/professional-v1`
LIVE/main: untouched

## 61. Test-calendar service boundary
`src/features/agenda/test-calendar-service.js` wraps the existing test-calendar storage and existing `getUpcomingTests` / `upsertTestDate` functions. No storage key or calendar behavior was changed.

## 62. Agenda review state
`src/features/agenda/review-state.js` isolates candidate selection state from rendering. It does not persist anything.

## 63. Agenda import model
`src/features/agenda/import-model.js` isolates import lifecycle state: idle, analyzing, review, error. It does not call AI and is not mounted.

## 64. Agenda view model
`src/features/agenda/agenda-view-model.js` creates a presentation boundary for student-scoped and upcoming agenda items. It is additive and not mounted.

## 65. Student lesson scope
`src/features/lessons/student-scope.js` exposes all/active/archived/deleted student lesson collections using the already extracted V4.78 visibility rules.

## 66. Lesson item model
`src/features/lessons/item-model.js` centralizes lesson-item normalization around the existing `sort_order` convention.

## 67. Lesson subject view model
`src/features/lessons/lesson-view-model.js` isolates subject grouping/presentation from the runtime.

## 68. Lesson activity state
`src/features/lessons/activity-state.js` isolates the mutable activity reference used by learning flows. It is not yet wired into the old runtime.

## 69. Central notification boundary
`src/core/notifications.js` provides a small notification boundary so features do not need to know the eventual UI implementation.

## 70. Central feature-error normalization
`src/core/feature-errors.js` provides consistent error-to-message conversion without changing existing runtime error handling.

## Safety after steps 61–70
- `index.html` was not replaced.
- No Supabase schema was changed.
- No LIVE/main change was made.
- No AI was added to the lesson editor.
- The agenda AI endpoint has still not been recreated or guessed.
- New modules remain additive until parity is verified.
